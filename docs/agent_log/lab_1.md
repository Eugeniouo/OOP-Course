## Эпизод 2. Выбор датасета

**Запрос:** сравнить кандидатов (Credit Approval; Autism Screening Adult;
Productivity Prediction of Garment Employees) и выбрать удобный набор под
требования Lab 1 и дальнейшие работы.

**Что получили:**
- Credit Approval — формально ок, но обезличенные `A1`–`A15` усложняют отчёты;
- Autism — мало непрерывных признаков, ARFF, риск утечки через `result`;
- Garment Employees — 1197 строк, готовый CSV, смешанные типы, пропуски в
  `wip`, понятные имена, отклик для регрессии.

**Что приняли:** Garment Employees; файл в `data/garments_worker_productivity.csv`.

**Что изменили относительно «взять как есть»:** заранее зафиксировали нюансы
для загрузчика и README — пустой `wip`, нормализация `department`
(`sweing` / `finishing `), `team` как категория, `date` не в матрицу признаков.

**Как проверили:** сверка с требованиями UCI-набора в условии Lab 1 и просмотр
реального CSV (1197 строк, 506 пустых `wip`, счётчики `department`).
